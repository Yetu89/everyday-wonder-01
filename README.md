# everyday-wonder-01

## The bounty

"Everyday Wonder, Two Days to Find the Line" — write one sentence, at most 200 characters, about a small moment of wonder in everyday life, judged pairwise by an AI judge that rewards surprise. Prize pool $2, free to enter, closes Thu 26 Nov 2026 18:35 WIB.

## The entry

> The lift doors opened on a stranger humming the exact song I had stuck in my head all morning, and for a second the building felt in on it.

139 characters. Grok (grok-4.3) scored this candidate 9/10 and picked it as the winner: a personal sync with a stranger, plus the building feeling "in on it" — the sharpest uncanny reframing of an ordinary moment.

## How to run

```sh
OUTPUT_DIR=/tmp/out node main.ts
```

This writes the entry to `$OUTPUT_DIR/entry.txt` (default `/output`), exactly as-is with no trailing newline, after validating every gate (one sentence, 1–200 characters, no whitespace-only, no control characters, no leading/trailing whitespace, no newline) and verifying the file byte-for-byte.
